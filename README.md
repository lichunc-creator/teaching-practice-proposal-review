# 教學實踐研究計畫審查 Skill

給 Claude 使用的 skill：依 8 項重點審查教育部教學實踐研究計畫書（或類似的教學介入計畫）。

## 檢查內容

1. 是否反映教學現場問題
2. 文獻是否對齊問題、支持因果關係
3. 理論與問題是否對應
4. 理論介紹是否清楚、介入研究支持是否足夠
5. 理論轉為教學策略：吻合度、創新性、能否解決問題
6. 教學介入是否清楚、對應評量、回應研究目的
7. 步驟可行性、與理論吻合、文獻引用正確性（DOI、孤兒文獻、漏列文獻）
8. AI 感、錯字、誤植、重複段落、語意不齊

## 安裝

1. 下載本 repo（Code → Download ZIP），或只下載 `teaching-practice-proposal-review/SKILL.md`。
2. 在 Claude 左側邊欄點「Customize」→「Skills」→「新增」上傳；若選單沒有上傳 skill 的選項，可選「使用 Claude 建立」，把 SKILL.md 內容貼給 Claude，請它照內容建立。
3. 之後對 Claude 說「檢查這份教學實踐計畫」並附上計畫書 PDF 即可。

## 建議連線

- PubMed 連接器：用來核對文獻是否存在、DOI 與引用數據是否正確。
- EndNote（選用）：查詢個人文獻庫。

沒有這些連線時，其他檢查項目仍可正常運作。
